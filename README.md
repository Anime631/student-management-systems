#  Student Management System

A beginner-friendly Student Management System built using Python.

This project was created as part of my Python learning journey to
practice functions, dictionaries, loops, conditional statements,
and basic CRUD operations.

##  Features

-  View all students
-  Search for a student
-  Add a student
-  Update student marks
-  Delete a student
-  Calculate average marks
-  Find the highest scorer
-  Exit the program

##  Technologies Used

- Python 3

##  Concepts Practiced

- Variables
- User input
- Conditional statements
- For loops
- While loops
- Functions
- Parameters
- Dictionaries
- Dictionary methods
- Searching
- Updating and deleting data
- Basic data processing
